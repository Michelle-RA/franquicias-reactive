# 📦 Aplicación Java Reactiva - Spring WebFlux + Project Reactor

Esta es una aplicación Java reactiva basada en **Spring WebFlux** y **Project Reactor**, que se conecta a una base de datos desplegada en **Clever Cloud**.

---

## 🚀 Tecnologías
- Java 17
- Spring Boot (WebFlux)
- Project Reactor
- R2DBC (Reactive Relational Database Connectivity)
- PostgreSQL (base de datos en Clever Cloud)
- Maven o Gradle
- Docker (opcional para despliegue)

---

## ⚙️ Requisitos

Antes de ejecutar la app necesitas tener instalado:

- [Java 17](https://adoptium.net/)
- [Gradle](https://gradle.org/)
- [Git](https://git-scm.com/)
- [Docker](https://www.docker.com/) (opcional)
